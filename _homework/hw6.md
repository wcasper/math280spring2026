**Problem 1:**

* (a) Prove that if $$x,y,z\in\mathbb R$$ with $$x < y$$ and $$z<0$$ then $$zx > zy$$.
* (b) Prove that if $$x\neq 0$$ then $$x^2>0$$.

**Problem 2:**

A subset $$A\subseteq \mathbb R$$ is called an **inductive set** if $$1\in A$$ and $$x\in A\Rightarrow (x+1)\in A$$ for all $$x\in\mathbb R$$.
The set $$\mathbb N$$ of **natural numbers** is defined to be the set of all numbers belonging to every inductive set.
Then as a *notation*, $$2=1+1$$, $$3=2+1$$, $$4=3+1$$ and so on.

* (a) Prove that $$1,2,$$ and $$3$$ are all natural numbers (ie. that they are in *every* inductive set)
* (b) Prove that $$2\neq 1$$.
* (c) Prove that $$3\neq 2$$ and that $$3\neq 1$$.

**Problem 3:**

Prove the following

* (a) If $$x\in \mathbb N$$ then $$1\leq x$$.
* (b) If $$k\in \mathbb N$$ then there does not exist $$y\in\mathbb N$$ with $$k < y < k+1$$.

<details>
  <summary>Reveal hint</summary>

  For part (a):
  Consider the set $$S=\{x\in\mathbb R: 1\leq x\}$$.


  For part (b):
  Consider the set $$S=\{x\in \mathbb N: \nexists y\in\mathbb N\ \text{with}\ x < y < k+1\}.$$

  In both parts, prove that the set $$S$$ is an inductive set and therefore $$\mathbb N\subseteq S$$.
</details>

**Problem 4:**

Suppose that $$A$$ and $$B$$ are nonempty subsets of $$\mathbb R$$ which are both bounded above.  Prove the following

* (a) if $$A\subseteq B$$ then $$\sup(A)\leq \sup(B).$$

* (b) Let $$C=\{a+b: a\in A,\ b\in B\}$$.  Then $$C$$ is bounded above and $$\sup(C)\leq \sup(A) + \sup(B)$$.
