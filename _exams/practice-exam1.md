Solve each of the following problems.
If the problem asks for a proof, be sure to carefully justify your work, including any theorems from class.

Note: you may NOT use a theorem or result from class to prove something when it makes the problem entirely trivial.  If you are unsure whether a particular theorem or result is allowed, just ask!

## Problem 1 (True or False)
For each of the following, write TRUE if the statement is true and FALSE if the statement is false.  NO explanation is needed.

a) 
$$\{2,3,2,1,1\} = \{1,2,3\}$$

b) 
$$\varnothing\in \{1,2,3\}$$

c) 
$$\varnothing\in \{\{\varnothing\}\}$$

d) 
The set $$\{\mathbb{R}\}$$ has infinitely many elements

e)
Every set is a subset of itself

f)
$$\{1,2\}\subseteq \{1,\heartsuit,\{Valentine,2\}\}$$

g)
If $$A\subseteq B$$ then $$P(A)\subseteq P(B)$$

h)
The sets $$\{x\in \mathbb R: x^2=x\}$$ and $$\{0,1\}$$ are equal

i)
$$A - B = A\cap B^c$$

j)
$$P(\varnothing) = \varnothing$$


## Problem 2
Use truth tables to prove each of the following.

a) The following is a tautology
$$(P\wedge Q)\Rightarrow (Q\Rightarrow P)$$

b) Show that the following mathematical statements are equivalent
$$P\Leftrightarrow Q$$ and $$(\sim P\vee Q)\wedge (\sim Q\vee P)$$

## Problem 3

Use **proof by contradiction** to prove that $$\sqrt{21}$$ is irrational.

Additional practice: try to prove $$\sqrt[3]{2}$$ is irrational.

## Problem 4

Use a **direct proof** to prove that if $$d$$ divides $$x$$ and $$d$$ divides $$y$$, then $$d^2$$ divides $$x^2+3xy - y^2$$.

## Problem 5

Carefully consider the following statement.

If $$xy$$ is not divisible by 5, then neither $$x$$ nor $$y$$ are divisible by 5. 

a) Carefully state the contrapositive of this statement.

b) Prove the contrapositive statement.

c) Explain why proving the contrapositive of a statement actually proves the original statement.

## Problem 6

Use a **proof by cases** to prove that $$2n^2+n+1$$ is not divisible by $$3$$ for all $$n$$.


## Problem 7

a) State the definition of the binomial coefficient $$\binom{n}{k}$$

b) State the Binomial Theorem

c) Use the Binomial Theorem to prove that for any integer $$n\geq 0$$

$$10^n+(-1)^{n+1}\quad\text{is divisible by $11$}.$$

Hint: 10^n = (-1 + 11)^n

## Problem 8

Use induction to prove that for any integer $$n\geq 0$$,

$$\int_0^\infty x^ne^{-x}dx = n!$$

## Problem 9

Prove that 

$$(A-B)-C = (A-C)-(B-C)$$
