### Directions
Solve the following problems and type up your solutions.  Your solutions should be provided in one of the following formats (in order of preference)
* typed up in $$\LaTeX$$ and submitted as a PDF on Canvas
* written legibly on blank paper, scanned into a PDF and then uploaded on Canvas
* written on ancient parchement with a quill and then flown to the instructor via owl post like in Harry Potter

If you go with the first strategy, you may wish to check out Overleaf which is a free and intuitive website for generating $$\LaTeX$$ documents online.
If you wish to use the second method and don't own a scanner at home, you can check out the numerous scanning apps available for smartphones.

**Problem 1:**

Use a truth table to determine whether each of the following is a **tautology**, a **contradiction**, or neither.

* (a)  $$P\wedge \sim P$$
* (b)  $$(P\wedge Q)\vee(\sim P \wedge \sim Q)$$
* (c)  $$(A\wedge B)\vee(A\wedge \sim B)\vee (\sim A\wedge B)\vee (\sim A\wedge\sim B)$$
* (d)  $$P\Rightarrow (P\Rightarrow (P\Rightarrow Q))$$

**Problem 2:**

Use a truth table to determine whether each of the following pairs of propositions is equivalent.

* (a) $$P\vee P$$ and $$P$$
* (b) $$\sim(P\vee \sim Q)$$ and $$\sim P\wedge Q$$
* (c) $$(P\Rightarrow Q)\Rightarrow R$$ and $$(P\wedge \sim Q)\vee R$$

**Problem 3:**

* (a) Use a **direct proof** to show that for any integer $$n$$, if $$n$$ is even then $$n^2$$ is divisible by $$4$$.

* (b) Use **proof by cases** to show that for any integer $$n$$ the number $$n(n+1)(2n+1)$$ is divisible by $$6$$.

* (c) Use **proof by contraposition** to show that for any real number $$x$$, if $$x^3+x > 0$$ then $$x > 0$$.

* (d) Use **proof by contradiction** to show that for any positive integers $$a$$ and $$b$$, if $$a < b$$ and $$ab < 3$$ then $$a=1$$.


**Problem 4:**

Let 

$$P = \{2,3,5,7,11,13\}$$

$$O = \{3,5,7,9,11,13\}$$

$$F = \{1,2,3,5,8,13\}$$

Determine the value of each of the following sets

* (a) $$P\cup O$$
* (b) $$P\cap O$$
* (c) $$F\cap (P\cap O)$$
* (d) $$P - (F\cap O)$$


**Problem 5:**

Let $$A$$ and $$B$$ be sets.  Prove the following two statements, which are called **de Morgan's Laws**

* (a) $$(A\cap B)^c = A^c\cup B^c$$
* (b) $$(A\cup B)^c = A^c\cap B^c$$


**Problem 6:**

Consider again the sets $$P$$, $$O$$, and $$F$$ from Problem 4.  Ostensibly, we can make all kinds of new sets out of just these three by using unions, intersections, complements and differences.
For example, we can make $$F\cup O\cup P$$, $$P\cap O\cup F$$, $$P-(O\cup F)$$, $$(P-F)\cup (F-P)$$, and so on.
However, many of these expressions end up giving us the same set!

Determine how many sets we can actually get by combining together $$P$$, $$O$$, and $$F$$ using intersections, unions, differences, and complements.
Make sure to carefully explain your reasoning.
